# Iced Americano, Even in Winter

Use this record when recommending coffee or a cafe to the user, including for studying, chatting, or visiting cafes while traveling.

The user dislikes flavored coffee, meaning coffee made from beans with added flavoring. It is fine for a cafe to offer it, but the user does not want to drink it, even for free. Clearly labeling it is fine; the user gets upset when served flavored coffee without being told.

The user likes iced Americanos and drip coffee.

The user dislikes sugar in iced Americanos and wants only coffee, water, and ice.

Lattes are also acceptable, but the user generally prefers iced Americanos.

For iced Americanos, the user prefers coffee described as "medium to light" and dislikes bitterness.

For lattes, the user likes slightly bitter coffee beans.

The user wants plenty of ice in an iced Americano. At least half the cup should still be filled with ice when the drink is served.

Some cafes, especially those accustomed to making hot coffee, underestimate how quickly hot espresso melts ice and serve a watery drink. The user dislikes this and wants ice to remain in the drink.

For lattes and similar drinks, the user likes plenty of sugar: about two to three sugar cubes for a drink with a double shot of espresso.
