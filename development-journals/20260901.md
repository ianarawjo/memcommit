--memory와 --input은 모두 Add 내용의 출처지만 의미는 다릅니다. --memory는 옵션에 적힌 문자열 자체가 Memory이고 반복할 수 있지만, --input은 파일 경로나 -를 받아 내용을 읽고 줄별 Memory로 변환합니다. 외부 CLI 표기인 --input은 cmd 서명에는 드러나는 것이 맞고, 그 아래 애플리케이션에는 AddRequest로 통합되어야 합니다. 따라서 옵션을 합치기보다 “어떤 Add 입력 방식인지 결정하고 요청으로 변환하는 단계”를 별도 함수로 빼는 편이 자연스럽습니다.

--paste는 실제로 mem add --paste에서 사용하는 사람 대상의 대화형 입력 방식입니다. 터미널에 붙여넣은 원문을 화면에 노출하지 않고 줄 수만 보여주며, F2나 Ctrl-D로 완료하면 비어 있지 않은 각 줄을 Memory로 저장하고 Escape나 Ctrl-C로 취소합니다. --input -이 파이프와 자동화를 위한 stdin 입력이라면, --paste는 사람이 클립보드 내용을 안전하게 붙여넣고 한 체크포인트로 저장하는 흐름입니다.
