OPERATIONS                                                                                                                                                                          
┌ BROWSE & NAVIGATE ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ NO LLM · 检查当前位置和可用 Context，然后在 Context 命名空间中移动。                                                                                                            │ 
│ ▸ mem status ─┬ 显示当前 Context 的清单、前五个直接 Memory、关系和最新 checkpoint。                                                                                             │ 
│               └ WHEN · 了解当前 Context 包含什么、如何连接以及最近应用了哪些 operation 时。                                                                                     │ 
│ ▸ mem pwd ─┬ 输出当前规范 Context 名称，而不加载其内容。                                                                                                                        │ 
│            └ WHEN · 在脚本或终端中确认当前活动 Context 时。                                                                                                                     │ 
│ ▸ mem contexts ─┬ 浏览本地 Context 和可读的跨 Profile Context 视图，而不进行切换。                                                                                              │ 
│                 └ WHEN · 查看当前 Profile 可访问的全部 Context 时。                                                                                                             │ 
│ ▸ mem list ─┬ 列出 Context 的直接项目——Memory、Memory reference、query view 和嵌入的 Context——以及可读子 Context；-r 递归包含后代和嵌入 Context 中的项目，ls 是简短别名。       │ 
│     (ls)    └ WHEN · 检查 Context 的结构和直接内容时。                                                                                                                          │ 
│ ▸ mem show ─┬ 显示 Memory、reference、嵌入的 Context，或当前/指定 Context 的直接内容。                                                                                          │ 
│             └ WHEN · 阅读已知项目或 Context 的完整内容时。                                                                                                                      │ 
│ ▸ mem switch ─┬ 进入交互式 Context 选择器，或切换到明确指定的 Context。                                                                                                         │ 
│               └ WHEN · 将工作位置移动到另一个现有 Context 时。                                                                                                                  │ 
│ ▸ mem checkout ─┬ 使用类似 Git 的语法切换 Context；使用 -b 时创建并切换到新的 Context 分支。                                                                                    │ 
│                 └ WHEN · 以类似 Git 的工作流切换或创建分支时。                                                                                                                  │ 
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
                                                                                                                                                                                    
┌ CREATE, COPY & CONNECT ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ NO LLM · 创建 Context 或 Memory，复制或导入资源，或连接现有材料。                                                                                                               │ 
│ ▸ mem init ─┬ 创建一个新的空 Context，并将其设为当前工作 Context。                                                                                                              │ 
│             └ WHEN · 为新主题、任务或一组 Memory 建立独立工作区时。                                                                                                             │ 
│ ▸ mem add ─┬ 向当前或指定 Context 添加一个或多个 Memory。                                                                                                                       │ 
│            └ WHEN · 将一个或多个事实、指令或笔记直接添加到 Context 时。                                                                                                         │ 
│ ▸ mem branch ─┬ 将 Context 或其子树复制为新分支并切换到该分支。                                                                                                                 │ 
│               └ WHEN · 在保留原始内容的同时独立编辑 Context 或子树时。                                                                                                          │ 
│ ▸ mem import ────┬ 按值导入干净基线的 Profile、Context 树或 Memory，同时保留资源身份。                                                                                          │ 
│     [PARTIAL]    └ WHEN · 将外部提供的材料带入本地管理的 store 时。                                                                                                             │ 
│ ▸ mem reference ─┬ 将一个直接 Source Memory 版本复制到 Target，作为不可变的只读 snapshot。                                                                                      │ 
│                  └ WHEN · 即使 Source 后续改变或消失，也要保留某个精确 Memory 版本时。                                                                                          │ 
│ ▸ mem embed ─┬ 在保留 Source 所有权的同时，将指向一个 Memory 或 Context 的实时链接放入本地 Target。                                                                             │ 
│              └ WHEN · 在另一个 Context 中复用 Memory 或 Context，并跟随 Source 后续变化时。                                                                                     │ 
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
