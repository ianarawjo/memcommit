# Confirmed bug index · strict live-debugging handoff

Status: **provisional**. This index covers the completed six-world core and
transform ledgers (1,350 attempts). The serialized admin phase is still
pending, so current-only operations are not promoted beyond their observed
workflow boundary.

The strict classification is deliberately narrower than the world issue
files. An item is a **confirmed actual bug** only when execution demonstrated
wrong selected material, a false semantic finding, unsupported asserted fact,
cross-world state, a broken promised recovery/review identity, or a published
mutation with lost meaning. A documented independent-frame contract, missing
capability, opaque explanation, output-reuse cost, or surprising but
fail-closed provider response belongs under **UX/contract friction** or
**candidate**, even when it repeated.

Priorities describe the observed user consequence: **P0** can operate on the
wrong world/target; **P1** can silently create, preserve, or remove wrong
meaning or defeat recovery; **P2** blocks a workflow or trusted review; **P3**
adds bounded durable noise. Every externally reportable world issue ID appears
exactly once below; an explicitly internal-only non-defect disposition remains
in its world record and does not enter this handoff index.
