│                └ WHEN · 여러 구체적인 사례나 예시에서 더 일반적인 Rule 또는 조건 명제를 추론할 때.                                                                              │

│                  └ WHEN · 추상적인 개념이나 조건에서 더 구체적인 여러 후보 Rule 또는 Case를 만들 때.                                                                            │

│                  └ WHEN · 원본을 교체하지 않고 Memory 내용을 다른 언어로 읽거나 재사용할 때.                                                                                    │

│               └ WHEN · 의미 해석이 필요한 자연어 지침에 따라 Memory를 제거하거나 다시 쓸 때.                                                                                    │

│             └ WHEN · 겹침, 충돌, 새로 합성된 내용을 의미적으로 검토하면서 두 작업 묶음을 결합할 때.                                                                             │
