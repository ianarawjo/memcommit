│ NO LLM · Inspect the current location and available Contexts, then move through the Context namespace.                                                                          │ 
│ ▸ mem status ─┬ Show the current Context's inventory, first five direct Memories, relationships, and latest checkpoints.                                                        │ 
│               └ WHEN · Getting oriented to what the current Context contains, how it is connected, and which operations were recently applied.                                  │ 
│ ▸ mem pwd ─┬ Print the current canonical Context name without loading its contents.                                                                                             │ 
│            └ WHEN · Confirming the active Context in a script or terminal.                                                                                                      │ 
│ ▸ mem contexts ─┬ List local Contexts and readable cross-Profile Context views.                                                                                                 │ 
│                 └ WHEN · Exploring every Context currently available to the Profile.                                                                                            │ 
│ ▸ mem list ─┬ List a Context's direct items—Memories, Memory references, query views, and embedded Contexts—and its readable child Contexts. Use -r to recursively include      │

│             └ WHEN · Inspecting the structure and direct contents of a Context.                                                                                                 │

│             └ WHEN · Reading the complete content of a known item or Context.                                                                                                   │

│               └ WHEN · Moving the working position to another existing Context.                                                                                                 │

│                 └ WHEN · Using a Git-like workflow to switch or create a branch.                                                                                                │
