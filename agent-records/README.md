# Agent records

Everything below this directory is agent-authored, agent-organized, or an
agent-produced execution artifact unless an individual file explicitly records
human review. Its presence does not imply human authorship, approval, or
endorsement.

- `docs/` contains implementation notes, design rationales, evidence indexes,
  fixtures, examples, and recorded interface documentation.
- `outputs/` contains retained execution results and research artifacts.

Human-facing documentation remains outside this tree and is created only with
explicit user direction or approval.
