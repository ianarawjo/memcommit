┃ ▾ mem add                Add one or more Memories to the current or explicit Context.           ┃ 
┃                          USE WHEN: Adding one or more facts, instructions, or notes directly to ┃ 
┃                                    a Context.                                                   ┃ 
┃   FLOW      · Text or file -> Context Memories                                                  ┃ 
┃   EXECUTION · DETERMINISTIC                                                                     ┃ 
┃   EFFECT    · Changes the selected Context                                                      ┃ 
┃   RANGE     · One exact target Context                                                          ┃ 
┃   COPY OR LINK                                                                                  ┃ 
┃   Text passed to Add is always stored literally as Memory content. Entering a Memory UID or     ┃ 
┃   Context name does not copy that object; it creates a new Memory containing that text.         ┃ 
┃   - INDEPENDENT WORK · Branch the containing Context and merge it later, or copy the Memory     ┃ 
┃     content and add it directly.                                                                ┃ 
┃   - EXACT MEMORY VERSION · Use mem reference to retain an immutable snapshot of the reviewed    ┃ 
┃     Source Memory.                                                                              ┃ 
┃   - LIVE MEMORY · Use mem embed MEMORY --from SOURCE to follow the Source Memory's current      ┃ 
┃     content.                                                                                    ┃ 
┃   - EXISTING CONTEXT · Use mem embed. The parent stores only the Context identity; the child    ┃ 
┃     Memories remain in the child, although recursive operations may traverse them.              ┃ 
┃   FORM 1 · mem add "[memory]" (add one Memory to the current Context)                           ┃ 
┃   FORM 2 · mem add (open the interactive multi-Memory editor)                                   ┃ 
┃   FORM 3 · mem add --memory "[memory]" --memory "[memory]" (add an explicit batch)              ┃ 
┃   FORM 4 · mem add --input [file] (add one Memory per non-empty line)                           ┃ 
┃   FORM 5 · mem add --paste (paste one or more Memories)                                         ┃v
