│ LLM-BASED · Uses LLM semantic analysis to restructure, derive, translate, curate, or reconcile content.                                                                         │ 
│ ▸ mem atomize ─┬ Analyze composite Memories and separate their distinct propositions into independently reviewable Memories.                                                    │ 
│                └ WHEN · Untangling requirements or claims that were written together so each can be reviewed and revised independently.                                         │ 
│ ▸ mem distill ─┬ Derive higher-level Rules or condition propositions from Case or Example propositions in a bounded Context, optionally guided by a Goal.                       │ 
│                └ WHEN · Inferring more general Rules or condition propositions from several concrete cases or examples.                                                         │ 
│ ▸ mem elaborate ─┬ Expand an abstract Goal, Rule, or condition into multiple more specific candidate propositions.                                                              │ 
│                  └ WHEN · Generating several more concrete candidate Rules or Cases from an abstract concept or condition.                                                      │ 
│ ▸ mem translate ─┬ Generate and save a reusable translated view of one Context or Memory while preserving the original content.                                                 │ 
│                  └ WHEN · Reading or reusing Memory content in another language without replacing the original.                                                                 │ 
│ ▸ mem forget ─┬ Review keep/edit/delete decisions for one instruction, then apply the accepted batch.                                                                           │ 
│               └ WHEN · Removing or rewriting Memories according to a natural-language instruction whose meaning must be interpreted.                                            │ 
│ ▸ mem resolve ─┬ Propose and verify minimum changes that make one bounded direct-Memory Context frame Fit YES.                                                                  │ 
│                └ WHEN · Deciding how to repair semantic conflicts or ambiguities within a bounded Context frame.                                                                │ 
│ ▸ mem update ─┬ Update Memories in the Target Context from Memories in the Source Context, asking the user to review and choose when needed.                                    │ 
│               └ WHEN · Updating an existing Context using newly verified Memories.                                                                                              │ 
│ ▸ mem meld ─┬ Semantically reconcile two Contexts, either into a separate Result or by incorporating proposed changes into an existing Target Context.                          │ 
│             └ WHEN · Combining two bodies of work when overlap, conflicts, and newly synthesized content must be reviewed semantically.                                         │ 
│ ▸ mem sever ─┬ Create a Result by selecting, transforming, or excluding Source Memories according to a Criteria Context.                                                        │ 
│              └ WHEN · Selecting or transforming Source content according to defined criteria.                                                                                   │
