│ NO LLM · 通过确定性的程序逻辑应用明确输入和已审查选择，以修改内容。                                                                                                             │ 
│ ▸ mem edit ─┬ 直接替换按 UID 或前缀选中的一个或多个 Memory 的内容。                                                                                                             │ 
│             └ WHEN · 直接纠正或替换特定现有 Memory 的内容时。                                                                                                                   │ 
│ ▸ mem replace ─┬ 预览并替换普通本地 Memory 中每个文字或明确 regex 匹配。                                                                                                        │ 
│                └ WHEN · 在已知本地 Context 范围内纠正、重命名或遮蔽精确文本时。                                                                                                 │ 
│ ▸ mem chunk ─┬ 在标题、段落或近似句子边界处机械拆分一个直接 Memory。                                                                                                            │ 
│              └ WHEN · Memory 已具有清晰的文本边界，并应将这些部分变为独立 Memory 时。                                                                                           │ 
│ ▸ mem delete ───┬ 选择要删除的 Context 或直接项目，或通过 locator、名称或 UID 指定它。                                                                                          │ 
│     (remove)    └ WHEN · 移除不再需要的特定 Context 或项目时。                                                                                                                  │ 
│ ▸ mem clear ─┬ 确认后移除当前或指定 Context 中的所有直接项目。                                                                                                                  │ 
│              └ WHEN · 保留 Context 本身但清空其内容时。                                                                                                                         │ 
│ ▸ mem merge ─┬ 将 Source 独有项目添加到当前 Target，保持精确匹配不变，并在已存项目冲突时选择 Source 或 Target。                                                                 │ 
│              └ WHEN · 追加 Source 独有项目，或将复制/分支的 Context 合回当前 Context，且不进行语义合成时。                                                                      │ 
│ ▸ mem dedup ─┬ 审查已确认的重复组，在每组中保留一个现有 Memory，并在 Apply 时删除其余项。                                                                                       │ 
│              └ WHEN · 删除已确认的语义重复项，同时保留一个精确的现有 Memory 及其 UID 时。                                                                                       │

┌ SEMANTIC TRANSFORMATIONS ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ LLM-BASED · 使用 LLM 语义分析来重组、推导、翻译、筛选或协调内容。                                                                                                               │ 
│ ▸ mem atomize ─┬ 分析复合 Memory，并将其中不同的命题拆分为可独立审查的 Memory。                                                                                                 │ 
│                └ WHEN · 解开写在一起的要求或主张，使每一项都能独立审查和修改时。                                                                                                │ 
│ ▸ mem distill ─┬ 从有界 Context 中的 Case 或 Example 命题推导更高层的 Rule 或条件命题，可由 Goal 提供可选引导。                                                                 │ 
│                └ WHEN · 从多个具体案例或示例推导更一般的 Rule 或条件命题时。                                                                                                    │ 
│ ▸ mem elaborate ─┬ 将抽象 Goal、Rule 或条件展开为多个更具体的候选命题。                                                                                                         │ 
│                  └ WHEN · 从抽象概念或条件生成若干更具体的候选 Rule 或 Case 时。                                                                                                │ 
│ ▸ mem translate ─┬ 生成并保存一个 Context 或 Memory 的可复用翻译视图，同时保留原始内容。                                                                                        │ 
│                  └ WHEN · 在不替换原文的情况下，以另一种语言阅读或复用 Memory 内容时。                                                                                          │ 
│ ▸ mem forget ─┬ 针对一条指令审查保留、编辑或删除决定，然后应用已接受的批次。                                                                                                    │ 
│               └ WHEN · 依据需要解释含义的自然语言指令删除或改写 Memory 时。                                                                                                     │ 
│ ▸ mem resolve ─┬ 提出并验证使一个有界直接 Memory Context frame 达到 Fit YES 的最小修改。                                                                                        │ 
│                └ WHEN · 决定如何修复有界 Context frame 中的语义冲突或歧义时。                                                                                                   │ 
│ ▸ mem update ─┬ 使用 Source Context 中的 Memory 更新 Target Context 中的 Memory，并在需要时要求用户审查和选择。                                                                 │ 
│               └ WHEN · 使用新验证的 Memory 更新现有 Context 时。                                                                                                                │ 
│ ▸ mem meld ─┬ 在语义上协调两个 Context，可生成独立 Result，也可将提议的修改纳入现有 Target Context。                                                                            │ 
│             └ WHEN · 合并两组工作，并需要对重叠、冲突和新合成内容进行语义审查时。                                                                                               │ 
│ ▸ mem sever ─┬ 依据 Criteria Context 选择、转换或排除 Source Memory，以创建 Result。                                                                                            │ 
│              └ WHEN · 依据明确标准选择或转换 Source 内容时。                                                                                                                    │
