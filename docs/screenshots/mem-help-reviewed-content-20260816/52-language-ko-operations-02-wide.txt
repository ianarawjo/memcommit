OPERATIONS                                                                                                                                                                          
┌ BROWSE & NAVIGATE ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ NO LLM · 현재 위치와 사용할 수 있는 Context를 확인하고 Context namespace를 이동합니다.                                                                                          │ 
│ ▸ mem status ─┬ 현재 Context의 inventory, 처음 다섯 개의 직접 Memory, 관계 및 최신 checkpoint를 보여줍니다.                                                                     │ 
│               └ WHEN · 현재 Context에 무엇이 있고 어떻게 연결되며 최근 어떤 operation이 적용됐는지 파악할 때.                                                                   │ 
│ ▸ mem pwd ─┬ 내용을 불러오지 않고 현재 canonical Context 이름을 출력합니다.                                                                                                     │ 
│            └ WHEN · script나 terminal에서 활성 Context를 확인할 때.                                                                                                             │ 
│ ▸ mem contexts ─┬ 전환하지 않고 로컬 Context와 읽을 수 있는 Profile 간 Context view를 탐색합니다.                                                                               │ 
│                 └ WHEN · 현재 Profile에서 사용할 수 있는 모든 Context를 살펴볼 때.                                                                                              │ 
│ ▸ mem list ─┬ Context의 직접 항목—Memory, Memory reference, query view, embedded Context—과 읽을 수 있는 하위 Context를 나열합니다. -r은 descendant 및 embedded Context         │ 
│     (ls)    │ 항목까지 재귀적으로 포함하며 ls는 짧은 alias입니다.                                                                                                               │ 
│             └ WHEN · Context의 구조와 직접 내용을 살펴볼 때.                                                                                                                    │ 
│ ▸ mem show ─┬ Memory, reference, embedded Context 또는 현재/지정 Context의 직접 내용을 보여줍니다.                                                                              │ 
│             └ WHEN · 알고 있는 항목이나 Context의 전체 내용을 읽을 때.                                                                                                          │ 
│ ▸ mem switch ─┬ 대화형 Context picker로 들어가거나 명시한 Context로 전환합니다.                                                                                                 │ 
│               └ WHEN · 작업 위치를 다른 기존 Context로 옮길 때.                                                                                                                 │ 
│ ▸ mem checkout ─┬ Git 방식 문법으로 Context를 전환하며, -b를 사용하면 새 Context branch를 만들고 전환합니다.                                                                    │ 
│                 └ WHEN · Git과 유사한 흐름으로 branch를 전환하거나 생성할 때.                                                                                                   │ 
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
                                                                                                                                                                                    
┌ CREATE, COPY & CONNECT ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ NO LLM · Context나 Memory를 만들고, resource를 복사·가져오거나 기존 자료를 연결합니다.                                                                                          │ 
│ ▸ mem init ─┬ 새 빈 Context를 만들고 현재 작업 Context로 설정합니다.                                                                                                            │ 
│             └ WHEN · 새 주제, 작업 또는 Memory 묶음을 위한 별도 작업 공간을 시작할 때.                                                                                          │ 
│ ▸ mem add ─┬ 현재 또는 지정한 Context에 하나 이상의 Memory를 추가합니다.                                                                                                        │ 
│            └ WHEN · 하나 이상의 사실, 지침 또는 메모를 Context에 직접 추가할 때.                                                                                                │ 
│ ▸ mem branch ─┬ Context 또는 하위 트리를 새 branch로 복사하고 그곳으로 전환합니다.                                                                                              │ 
│               └ WHEN · 원본을 보존하면서 Context 또는 하위 트리를 독립적으로 수정할 때.                                                                                         │ 
│ ▸ mem import ────┬ resource identity를 유지하면서 clean-baseline Profile, Context tree 또는 Memory를 값으로 가져옵니다.                                                         │ 
│     [PARTIAL]    └ WHEN · 외부에서 제공된 자료를 로컬에서 관리하는 store로 가져올 때.                                                                                           │ 
│ ▸ mem reference ─┬ 하나의 직접 Source Memory 버전을 변경 불가능한 read-only snapshot으로 Target에 복사합니다.                                                                   │ 
│                  └ WHEN · Source가 나중에 변경되거나 사라져도 정확한 Memory 버전 하나를 유지할 때.                                                                              │ 
│ ▸ mem embed ─┬ Source 소유권을 유지하면서 하나의 Memory 또는 Context를 가리키는 live link를 로컬 Target 안에 둡니다.                                                            │ 
│              └ WHEN · Source의 이후 변경을 따라가면서 Memory나 Context를 다른 Context에서 재사용할 때.                                                                          │
