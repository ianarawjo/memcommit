# Help wording audit matrix

| Category | Operation | Summary | Flow | Execution | Effect | Range |
|---|---|---|---|---|---|---|
| MEMORIES | add | Add one or more Memories to the current or explicit Context. | Text or file -> Context Memories | DETERMINISTIC | Changes the selected Context | One exact target Context |
| ANALYZE & TRANSFORM | atomize | Split composite Memories for review; --evaluate performs an issue-scoped directional meld. | Context Memories -> reviewed atomic Memories | SEMANTIC | Changes material only after explicit acceptance | One selected Context frame |
| ANALYZE & TRANSFORM | audit | Run Duplicate, Ambiguity, and Conflict checks plus optional Rule Conformance, then review one saved report. | Context + Rules? -> saved Audit report | SEMANTIC | No Context content changes | One exact direct Context |
| CONTEXTS | branch | Copy a Context or subtree into a new branch and switch to it. | Context -> new Context branch | DETERMINISTIC | Creates a Context and switches to it | Source exact or lexical descendants |
| GROUND & EVALUATION | check-conformance | Check Ground examples or one Context against explicit Rules. | Rules + Ground Memories or Context -> Conformance report | SEMANTIC | Read-only; no Rule, Ground, Context, or Memory changes | One saved Ground, or one exact local Target and Rules Context |
| CONTEXTS | checkout | Switch Contexts using Git-style syntax; with -b, create and switch to a new Context branch. | Context locator -> current Context or new branch | DETERMINISTIC | Switches Context; -b also creates one | Branch Source exact or lexical descendants |
| HISTORY & RECOVERY | checkpoint | Save the current Context as a manual recovery point for Diff or Revert. | Context state -> checkpoint | DETERMINISTIC | Adds recoverable history; content is unchanged | — |
| MEMORIES | chunk | Preview and split one direct Memory by headers, paragraphs, or sentences. | Memory -> ordered Memory chunks | DETERMINISTIC | Changes the Source Context after confirmation | One direct Memory |
| MEMORIES | clear | Remove all direct items from the current or explicit Context after confirmation. | Context direct items -> empty Context | DETERMINISTIC | Destructive Context change after confirmation | One exact Context |
| ANALYZE & TRANSFORM | compare | Compare Memories in two Contexts and report what they share, what differs, and what appears only on one side. | Context <-> Context -> comparison report | SEMANTIC | Read-only; neither Context is treated as authoritative | Each side exact or readable descendants |
| SYSTEM | config | Read and write global configuration. | Configuration key <-> value | DETERMINISTIC | May change global configuration | — |
| CONTEXTS | contexts | Browse local Contexts and readable cross-Profile Context views without switching. | Profile access -> readable Context catalog | DETERMINISTIC | Read-only; current Context is unchanged | All readable Context names |
| MEMORIES | delete | Select a Context or direct item to delete, or name it by locator, name, or UID. | Context or direct item -> removed | DETERMINISTIC | Destructive change after confirmation | One exact Context or direct item |
| HISTORY & RECOVERY | diff | Inspect recorded Context or Update changes without applying them. | Recorded change -> diff report | DETERMINISTIC | Read-only | One exact Context or active Update |
| ANALYZE & TRANSFORM | distill | Derive reusable Rules from Case or Example propositions in a selected Context scope, using an optional Goal to focus relevance. | Case/Example Context + Goal? -> reviewed Rules | SEMANTIC | Source and Ground stay unchanged; standalone Apply may create a new Result | One exact local Source, its readable descendants, or one bound Ground candidate frame |
| MEMORIES | edit | Replace direct Memory content by UID or prefix in the current or explicit Context. | Memory -> replacement Memory content | DETERMINISTIC | Changes one direct Memory | One direct Memory in one exact Context |
| ANALYZE & TRANSFORM | elaborate | Propose candidate Rules from a Goal, or concrete Case propositions from existing Rules. | Goal -> suggested Rules; Rules -> suggested Case propositions | SEMANTIC | Read-only; every proposal remains suggested and unverified | One Goal or Rule set, inline or from one exact Ground revision |
| CONTEXTS | embed | Place a Child Context inside a target while retaining its identity and ownership. | Child Context -> parent Context placement | DETERMINISTIC | Changes target structure; Child identity is retained | One Child and one exact target |
| GROUND & EVALUATION | eval | Run and inspect staged semantic evaluation campaigns. | Evaluation fixtures -> campaign results | MIXED | Changes evaluation ledgers, not Context content | — |
| SEARCH & EXPLAIN | find | Search selected Contexts with explicit lexical-descendant and embedded-Context reach. | Context set + query -> ranked Memories | SEMANTIC | Read-only search | Selected roots; lexical and embedded reach are independent |
| SEARCH & EXPLAIN | find-ambiguities | Report ambiguous direct Memories in the current or explicit Context; no Context changes. | Context Memories -> ambiguity report | SEMANTIC | No Context content changes | One exact direct Context |
| SEARCH & EXPLAIN | find-conflicts | Report conflicting direct Memory pairs in the current or explicit Context; no Context changes. | Context Memories -> conflict report | SEMANTIC | No Context content changes | One exact direct Context |
| SEARCH & EXPLAIN | find-duplicates | Report duplicate direct Memories in the current or explicit Context; no Context changes. | Context Memories -> duplicate report | SEMANTIC | No Context content changes | One exact direct Context |
| GROUND & EVALUATION | fit | Judge whether two or more propositions can jointly hold under ordinary readings. | Propositions + optional background -> YES / MAY / NO | SEMANTIC | Read-only; changes no Context, Ground, Rule, Goal, or Memory | One complete frozen proposition set; Ground is an explicit adapter |
| MEMORIES | forget | Review keep/edit/delete decisions for one instruction, then apply the accepted batch. | Context + instruction -> reviewed curation batch | SEMANTIC | Changes Source only after reviewed acceptance | One exact direct Source frame |
| GROUND & EVALUATION | ground | Create or continue a reviewed Goal-Rules-Memories Ground workbench. | Dialogue + evidence -> reviewed Ground | SEMANTIC | Changes Ground records; Context changes require separate commands | — |
| SYSTEM | help | Enter the interactive command browser and open syntax help. | Operation catalog -> usage guidance | DETERMINISTIC | Read-only | — |
| ANALYZE & TRANSFORM | impact | Preview or inspect operation Impact; no Context changes occur before its reviewed Apply handoff. | Operation inputs or session -> impact report | MIXED | Impact is read-only; Apply is a separate reviewed handoff | Operation-owned Source and Target ranges |
| CONTEXTS | import | Import a clean-baseline Profile, Context tree, or Memory by value while preserving resource identity. | External resource -> local owned copy | DETERMINISTIC | Creates or changes local owned resources | Profile, exact Context, subtree, or one Memory |
| CONTEXTS | init | Create a named Context, optionally ensure its parents, and switch to it. | New Context name -> Context | DETERMINISTIC | Creates a Context and switches to it | One fresh exact name; optional lexical parents |
| GROUND & EVALUATION | init-study | Copy one Study baseline into an isolated participant/authority Profile pair. | Study baseline -> isolated Study Profiles | DETERMINISTIC | Creates isolated Profile stores and switches Profile | — |
| CONTEXTS | list | Browse child Contexts and direct items; ls is the equivalent compact spelling. | Context -> Context and direct-item listing | DETERMINISTIC | Read-only | One exact Context or lexical descendants |
| PROFILE & SHARING | lock | Lock the current Context, a recursive Context set, Memory, or Profile. | Resource -> write-protected resource | DETERMINISTIC | Changes protection metadata | Exact resource or recursive Context set |
| HISTORY & RECOVERY | log | Browse Context checkpoints, inspect one Memory lineage with --memory, search history, or list Profile command attempts. | Recorded history or query -> history report | MIXED | Read-only | One Context, one Memory lineage, or Profile attempts |
| ANALYZE & TRANSFORM | meld | Semantically reconcile two Contexts into either a separate Result or an authoritative Baseline. | PEER A + PEER B -> RESULT; INCOMING -> BASELINE | SEMANTIC | Symmetric mode requires a distinct empty Result; directional mode changes only the Baseline after reviewed Apply | Each side exact or readable descendants |
| ANALYZE & TRANSFORM | merge | Add Source-only items to the current Target, choosing Source or Target wherever stored items conflict. | Source Context -> current Target Context | DETERMINISTIC | Changes Target only after every required conflict has KEEP TARGET or TAKE SOURCE; Source stays unchanged | Exact roots or matching lexical descendants by complete relative path |
| PROFILE & SHARING | profile | Enter the interactive Profile selector, or manage complete local MemoryStore Profiles. | Profile registry <-> Profile administration | DETERMINISTIC | May switch, create, import, rename, or remove Profiles | — |
| SYSTEM | provider | Select and verify Codex, Ollama, or OpenRouter semantic execution. | Provider configuration <-> status or probe | DETERMINISTIC | May change provider configuration or make a probe request | — |
| CONTEXTS | pwd | Print the current canonical Context name without loading its contents. | Current Context pointer -> canonical name | DETERMINISTIC | Read-only; Context content is not loaded | — |
| SEARCH & EXPLAIN | query | Ask readable Context knowledge or an authorized concealed query-only view. | Readable source + question -> answer with references | SEMANTIC | No Context content changes; visible transcript may be retained | Exact, descendants, embeds, or authorized query-only view |
| SEARCH & EXPLAIN | rationale | Explain one Memory from recorded provenance and, when needed, inference. | Memory provenance -> rationale | MIXED | Read-only | One current or historical Memory |
| HISTORY & RECOVERY | redo | Redo the most recently undone recorded Context command. | Undo history -> restored command effects | DETERMINISTIC | Changes the affected Context set | — |
| MEMORIES | reference | Add a read-only Memory pointer; the Target stores identity metadata rather than copying content. | Source Memory -> Target Context reference | DETERMINISTIC | Adds reference metadata to the Target | One direct Source Memory and one exact Target |
| PROFILE & SHARING | rename | Rename the current or an explicit managed Profile without moving or rewriting its store; mem profile rename is the explicit equivalent. | Managed Profile name -> new Profile name | DETERMINISTIC | Changes registry metadata; store contents stay in place | — |
| HISTORY & RECOVERY | revert | Select a checkpoint and review restoration of one local Context. | Checkpoint -> restored Context state | MIXED | Changes one Context after restoration review | One exact local Context |
| ANALYZE & TRANSFORM | review | Enter an interactive Review session or stage semantic review responses; never apply Memories. | Saved analysis -> review responses | MIXED | No Context content changes | One saved operation artifact |
| ANALYZE & TRANSFORM | sever | Review Source against Criteria and create a derived Result while leaving Source unchanged. | Source Context + Criteria Context -> new Result Context | SEMANTIC | Creates reviewed Result; Source remains unchanged | Source exact or descendants; Criteria exact scoped frame |
| PROFILE & SHARING | share | Send one ordinary Context through a grant-backed receiver endpoint. | Owned Context -> receiver endpoint | DETERMINISTIC | External delivery; Source remains unchanged | One exact ordinary Source Context |
| SYSTEM | shell-init | Print opt-in shell integration for interactive command prefill. | Shell name -> integration script | DETERMINISTIC | Read-only; installation requires explicit shell evaluation | — |
| CONTEXTS | show | Show a Memory, reference, embedded Context, or the direct contents of a current/explicit Context. | Context or direct item -> rendered content | DETERMINISTIC | Read-only | One exact Context or direct item |
| CONTEXTS | status | Show current Context counts, recent Memories, and checkpoints. | Current Context -> status report | DETERMINISTIC | Read-only | Current exact Context |
| SEARCH & EXPLAIN | summarize | Show what Mem understands from a Context's visible ordinary Memories. | Context -> summary | SEMANTIC | Read-only | Exact Context or descendants plus embedded Contexts |
| CONTEXTS | switch | Enter the interactive Context picker, or switch to an explicit Context. | Context locator -> current Context pointer | DETERMINISTIC | Changes only the current Context pointer | One exact existing Context |
| SEARCH & EXPLAIN | trace | Trace one retained Memory through its recorded lineage. | Memory -> retained lineage | DETERMINISTIC | Read-only | One current or historical Memory |
| ANALYZE & TRANSFORM | translate | Show and save a reusable translation view; materialize it only through an explicit route. | Context or Memory -> translated view or materialization | SEMANTIC | Source unchanged; explicit routes may create or add material | One exact Context or one direct Memory |
| HISTORY & RECOVERY | undo | Undo the most recent recorded Context command across its affected Contexts. | Command history -> reversed Context effects | DETERMINISTIC | Changes every Context affected by that command | — |
| PROFILE & SHARING | unlock | Unlock the current Context, a recursive set, Memory, or Profile. | Protected resource -> writable resource | DETERMINISTIC | Changes protection metadata | Exact resource or recursive Context set |
| ANALYZE & TRANSFORM | update | Update Memories in the Target Context from Memories in the Source Context, asking the user to review and choose when needed. | Source Context -> Target Context | SEMANTIC | Changes only the local Target after Apply | Each endpoint exact or readable descendants |
