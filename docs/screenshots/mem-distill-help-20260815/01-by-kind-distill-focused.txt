┌ CONTEXTS ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ ▸ mem status     Show current Context counts, recent Memories, and checkpoints.                                                                                                 │ 
│ ▸ mem pwd        Print the current canonical Context name without loading its contents.                                                                                         │ 
│ ▸ mem contexts   Browse local Contexts and readable cross-Profile Context views without switching.                                                                              │ 
│ ▸ mem list (ls)  Browse child Contexts and direct items; ls is the equivalent compact spelling.                                                                                 │ 
│ ▸ mem show       Show a Memory, reference, embedded Context, or the direct contents of a current/explicit Context.                                                              │ 
│ ▸ mem switch     Enter the interactive Context picker, or switch to an explicit Context.                                                                                        │ 
│ ▸ mem checkout   Switch Contexts using Git-style syntax; with -b, create and switch to a new Context branch.                                                                    │ 
│ ▸ mem init       Create a named Context, optionally ensure its parents, and switch to it.                                                                                       │ 
│ ▸ mem branch     Copy a Context or subtree into a new branch and switch to it.                                                                                                  │ 
│ ▸ mem import     Import a clean-baseline Profile, Context tree, or Memory by value while preserving resource identity.                                                          │ 
│ ▸ mem embed      Place a Child Context inside a target while retaining its identity and ownership.                                                                              │ 
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
                                                                                                                                                                                    
┌ MEMORIES ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ ▸ mem add              Add one or more Memories to the current or explicit Context.                                                                                             │ 
│ ▸ mem reference        Add a read-only Memory pointer; the Target stores identity metadata rather than copying content.                                                         │ 
│ ▸ mem edit             Replace direct Memory content by UID or prefix in the current or explicit Context.                                                                       │ 
│ ▸ mem chunk            Preview and split one direct Memory by headers, paragraphs, or sentences.                                                                                │ 
│ ▸ mem forget           Review keep/edit/delete decisions for one instruction, then apply the accepted batch.                                                                    │ 
│ ▸ mem delete (remove)  Select a Context or direct item to delete, or name it by locator, name, or UID.                                                                          │ 
│ ▸ mem clear            Remove all direct items from the current or explicit Context after confirmation.                                                                         │ 
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
                                                                                                                                                                                    
┌ SEARCH & EXPLAIN ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ 
│ ▸ mem find              Search selected Contexts with explicit lexical-descendant and embedded-Context reach.                                                                   │ 
│ ▸ mem query             Ask readable Context knowledge or an authorized concealed query-only view.                                                                              │ 
│ ▸ mem summarize         Show what Mem understands from a Context's visible ordinary Memories.                                                                                   │ 
│ ▸ mem trace             Trace one retained Memory through its recorded lineage.                                                                                                 │ 
│ ▸ mem rationale         Explain one Memory from recorded provenance and, when needed, inference.                                                                                │ 
│ ▸ mem find-duplicates   Report duplicate direct Memories in the current or explicit Context; no Context changes.                                                                │ 
│ ▸ mem find-ambiguities  Report ambiguous direct Memories in the current or explicit Context; no Context changes.                                                                │ 
│ ▸ mem find-conflicts    Report conflicting direct Memory pairs in the current or explicit Context; no Context changes.                                                          │
